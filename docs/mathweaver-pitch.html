问题：答案从天上掉下来

传统教材呈现"打磨完毕的结果"而非"发现结果的过程"。证明是综合法——从公理到结论的线性路径——而思维的起点被抹去了。抽象代数这一关尤其残酷：从计算思维跃迁到结构思维，学生被要求直接接受定义。

结构被当起点而非终点
数学并非按欧几里得模式从已确立的公理线性演绎而来，而是通过猜想 → 反例 → 概念拉伸 → 证明分析的反复过程生长。"启发式"（数学如何被发现）与"证明逻辑"（数学如何被验证）是两套不同的逻辑——前者解释数学的产生，后者只解释它的合法性。 — Imre Lakatos, Proofs and Refutations (1963/1976), 借 Euler 多面体公式展开

传统教学 · 综合证明

  • 公理 → 定理, 线性演绎, 起点被隐藏
  • 反例被视为"错误", 需要绕开
  • 学生记忆结构, 不知结构为何如此
  • 评估靠正确率, 不评估发现能力

发现式学习 · Lakatos 循环

  • 猜想 → 反例 → 修正 → 收敛到定理
  • 反例是结构显现的下一步, 不是失败
  • 学生"走到"结构那里, 非被告知
  • 评估含猜想质量与修正轨迹

"结构是终点，不是起点。"

方法：让学习者走到结构那里

不预设路径。学生在猜想—反驳—修正的循环中自己走到数学结构。三件事同时成立：Lakatos 式发现循环、Z3 形式化裁决、四场耦合的认知建模。

Lakatos 猜想循环

1提原始猜想
›
2遇反例/批评
›
3概念拉伸
›
4证明分析
›
5修正收敛

第 3 步"概念拉伸"重新界定反例是否在概念外延内；第 4 步"证明分析"含 monster-barring（拒认反例）/ lemma-incorporation（把被反驳的引理补回假设）两种启发式动作。反例不是失败, 是结构显现的下一步。

Z3 形式化裁决 · 群公理编码

;; 群公理 → SMT 约束 (有限域 G) (declare-sort G 0) (declare-fun op (G G) G) (declare-const e G) (declare-fun inv (G) G) (assert (forall ((a b c G)) ; 结合律 (= (op (op a b) c) (op a (op b c)))))) (assert (forall ((a G)) (= (op e a) a))) ; 单位元 (assert (forall ((a G)) (= (op (inv a) a) e))) ; 逆元 ;; 裁决 "所有群都交换" → 否命题 ∃a,b: op(a,b)≠op(b,a) (check-sat) ; → sat (Z3 找到反例 S₃, |G|=6) (get-model) ; → op(σ₁,σ₂)=σ₃, op(σ₂,σ₁)≠σ₃

判定权在 Z3, 不在 LLM。LLM 只做转译与启发式引导。

四场耦合引擎 · 动力学模型

知识场K(t) ∈ [0,1]ⁿ
每概念掌握度向量; 随聚焦注意增长, 随挫败抑制
认知场C(t)
认知负荷; 由任务难度驱动, 持续衰减
情感场E(t)
挫败 × 自信; 由成功/失败率积分
交互场I(t)
动作密度 × 停留; 正向情感放大, 负向抑制

猜想引擎 + NL→Z3 已实现

自然语言猜想 → 自动转译 → Z3 裁决。四层 fallback 优先形式化, 每次裁决附苏格拉底式追问, 引导而非给答案。

NL 猜想› 解析归类› 路由› L1 Z3 ↘ L2 LLM+Z3 ↘ L3 LLM+启发式 ↘ L4 LLM › verdict + 追问
  • L1
    Z3 direct · 一阶可枚举结构 (有限群/环). 触发: Cayley 表可枚举. 例 "素数阶群循环" → Lagrange + 枚举验证 Z₃,Z₅,Z₇
  • L2
    LLM + Z3 · LLM 拆解为可验证子目标, Z3 逐项验证. 触发: 命题可分解. 例 "有限交换群 = 循环群直和"
  • L3
    LLM + 启发式 · 需归纳或高阶推理, 多步 LLM 交叉检验 + 置信度标注. 触发: 超出 Z3 表达力. 例 "同态核是正规子群"
  • L4
    LLM heuristic · 标注非权威. 触发: 上述均失败或开放性猜想. 仅给方向性反馈, 不下裁决
输入: 所有群都是交换群
verdict: refuted · 层级: L1 Z3 direct
反例: S₃ (6阶) · 耗时: 38ms
smt: ∀i,j. table[i][j]==table[j][i] → sat
追问: 你能找到哪两个元素不交换吗？

3D 对称群可视化 已实现

选择群元（如三循环），正四面体 (S₄) 动画旋转到对应对称位置——每个旋转就是一个置换。把"置换"从符号变成可看见的空间变换。WebGL 不可用时自动降级 SVG 投影。

Manim 动画管线 已实现

后端预渲染群运算、结合律、单位元、逆元等动画，前端按需播放。逐帧前进，可查看 Manim 源码。缺少依赖时自动生成 SVG 帧。

  • 每帧对应一个推理步骤
  • 逐帧播放 + 源码可见
  • SVG 帧降级保证可用

眼动认知负荷 演示

webgazer.js 用普通摄像头实时追踪注视点，通过注视时长与扫视频率估算认知负荷，叠加注视热力图。为认知场提供反应时之外的第二信号源。

Lean/Coq 的形式化能力是 MathWeaver L3 层的灵感来源——但它们面向证明完成, 不面向发现过程; MathWeaver 用启发式交叉检验替代重型形式化, 将验证嵌入发现循环内部, 而非作为终点工具。

  • 任意时刻仅一个 Agent 写共享状态 → 确定性可复现
  • 无锁无竞态, 调试时序清晰
  • 支持会话回放与 A/B 对照实验
  • 判定权集中在 Z3, LLM 仅辅助转译

工程质量与可靠性 v0.3.0

从"能跑"到"可靠"。v0.3.0 系统性修复了 LLM 协议一致性、Agent 异常隔离、Token 追踪与连接复用——每一项都有测试覆盖。

LLM 协议一致性

  • extract_content() 统一辅助函数, 兼容 dataclass 与 dict 响应
  • 全代码库 11 处调用点统一替换, 零协议分歧
  • 根因: LLMResponse 数据类与遗留 dict 返回值的混用

Agent 异常隔离

  • _safe_agent_run() 包装器: Agent 崩溃不再传播到 Orchestrator
  • 异常自动记录 + trace span 标记 ERROR
  • 调用方决定降级策略 (跳过/回退/报错)

LLM 客户端韧性

  • 指数退避重试: 429/5xx 自动重试, 最多 3 次
  • 连接池复用: httpx.AsyncClient 单例, 减少 TCP 握手开销
  • Token 使用量从硬编码 0 改为从响应累积追踪
